# Code Style

Loaded on every session (no `paths` frontmatter = unconditional, same
priority as CLAUDE.md).

- Prefer editing existing files over creating new ones.
- No comments unless the WHY is non-obvious — a hidden constraint, a
  workaround, a surprising invariant.
- No speculative abstractions. Solve the problem in front of you.
- Match the repo's existing formatting/lint config; don't introduce a new style.
