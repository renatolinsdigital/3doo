# Changelog

All notable changes to 3DOO are recorded here. Versions follow
[Semantic Versioning](https://semver.org): `MAJOR.MINOR.PATCH`.

- **MAJOR**: changes that break saved scenes, workflows or shortcuts users rely on.
- **MINOR**: new features that keep existing behaviour working.
- **PATCH**: bug fixes and small corrections.

New entries go under `Unreleased` until a version is cut. Group them under
`Added`, `Changed`, `Fixed` or `Removed`. How a version is cut, tagged and
published is in [docs/releasing.md](docs/releasing.md).

## [1.0.0] - 2026-11-13

First tracked release, and the first one tagged and published on GitHub. It
marks the editor as the hosted site served it on that date: vertex, edge and
face modelling with the full set of mesh operations, a non-destructive
modifier stack, booleans, OBJ and FBX import and export, `.3doo` projects with
opt-in autosave, the JavaScript scripting editor, the MCP server that lets AI
assistants build models in the editor (`3doo-mcp` 1.0.6), and a home page that
plays the demo reel. The
[release notes](https://github.com/renatolinsdigital/3doo/releases/tag/1.0.0)
describe it in full.

## Before 1.0.0

Releases before 1.0.0 are not listed. Until then 3DOO was built against a
private roadmap that moved back and forth between areas rather than in a
straight line, and its milestones would make little sense read from outside.
This log starts at 1.0.0, the first version meant to be followed in public.
